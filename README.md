# 終活リーガルクリニック

**一般社団法人 相続手続士業の会** が運営する、終活・相続・遺言書に関する無料チェックツールです。

🔗 **公開URL**：https://sozoku-expert.net/  
📄 **ツールURL**：（GitHub Pages公開後のURLを記載）

---

## 概要

病院の問診票形式で終活に必要な手続きを確認できるWebアプリケーションです。  
入力するだけで以下の書類を自動作成し、印刷・保存できます。

| 出力書類 | 内容 |
|---|---|
| 相続人関係図 | 法定相続人・法定相続分をSVGで自動描画 |
| 財産目録 | 不動産・預貯金・有価証券・保険・負債 |
| エンディングノート | 医療・葬儀希望・書類保管・デジタル遺品 |
| 生前契約一覧 | 解約が必要な契約のチェックリスト |
| 事前指示書 | 医療に関する希望（臓器提供・献体含む） |
| 終活処方箋 | 必要な対策のアドバイスカード |

---

## 特徴

- **完全クライアントサイド処理**：入力データはすべてブラウザ内で処理。サーバーへの送信は一切行いません。
- **一時保存機能**：`localStorage` を利用した途中保存・再開機能付き（高齢者向けUIを考慮）。
- **単一ファイル構成**：`index.html` 1ファイルで完結。外部CDN依存なし。
- **印刷対応**：A4印刷用CSSを内蔵。専門家への持参資料として利用可能。

## GitHub Pages での公開方法

1. 本リポジトリを GitHub 上に作成し、ファイルをプッシュ
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch` に設定
4. **Branch** を `main`、フォルダを `/ (root)` に設定して **Save**
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
